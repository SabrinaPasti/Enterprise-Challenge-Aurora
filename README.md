# Sobre o Projeto

Este projeto foi desenvolvido como solução para o desafio da Aurora, uma startup de HR Tech que utiliza dados para apoiar decisões mais conscientes na gestão de pessoas.

A proposta consiste na criação de uma landing page voltada ao mercado B2B, com o objetivo de apresentar a plataforma Aurora, destacar seus benefícios e converter visitantes em leads qualificados por meio de um formulário de contato.

# Objetivo

Desenvolver uma experiência clara, atrativa e estratégica para gestores de RH, CEOs e diretores, demonstrando como a Aurora transforma dados em insights para decisões mais seguras sobre talentos, desempenho e retenção.

# Funcionalidades
Apresentação da proposta de valor da Aurora
Destaque para benefícios e diferenciais da plataforma
Seção explicativa sobre a solução
Formulário para captação de leads
Layout responsivo para diferentes dispositivos
Aplicação de boas práticas de usabilidade e acessibilidade

# Ferramentas Utilizadas
Figma
HTML5
CSS3
JavaScript
Resultado

A landing page foi projetada para fortalecer a presença da Aurora no mercado B2B, comunicar sua proposta de valor de forma objetiva e gerar oportunidades de negócio através da captação de novos contatos.
